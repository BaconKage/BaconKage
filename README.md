## What I'm building

- **[Food Vision Backend](https://github.com/BaconKage/Food_Vision_Backend)** — FastAPI service that extracts foods and macros from a photo using OpenAI vision, validates the output with Pydantic, and syncs it into MongoDB meal plans.
- **[Ena](https://github.com/BaconKage/ena-flask-server)** — An emotionally-aware chatbot: Flask + Groq's LLaMA 3, with sentiment and entropy analysis driving context-aware responses.
- **[BhashaBuddy](https://github.com/BaconKage/BhashaBuddy)** — An offline AI writing tutor for NRI children. Compares OCR engines (Tesseract, EasyOCR, Google Vision) and gives feedback through a local LLM via Ollama.
- **[UniERP](https://github.com/BaconKage/UniERP)** — A React + TypeScript ERP system backed by Firebase.
- **[My Gym Admin](https://github.com/BaconKage/My_Gym_Admin_Backend)** — Node/Express API and React dashboard for managing gym members and sessions.
