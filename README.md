## Shipped

- **[MyGym](https://mygym.co.in)** - Gym management platform: member tracking, session scheduling, admin dashboard. Node/Express API + React frontend. ([backend](https://github.com/BaconKage/My_Gym_Admin_Backend), [admin panel](https://github.com/BaconKage/My_Gym_Admin_Page))
- **[BhashaBuddy](https://parampara-one.vercel.app)** - Offline AI writing tutor for NRI children. Compares OCR engines (Tesseract, EasyOCR, Google Vision) and gives feedback through a local LLM via Ollama, no paid APIs. ([repo](https://github.com/BaconKage/BhashaBuddy))

## Also building

- **[Food Vision Backend](https://github.com/BaconKage/Food_Vision_Backend)** - FastAPI service that extracts foods and macros from a photo using OpenAI vision, validates the output with Pydantic, and syncs it into MongoDB meal plans.
- **[Ena](https://github.com/BaconKage/ena-flask-server)** - Emotionally-aware chatbot built on Flask and Groq's LLaMA 3, using sentiment and entropy analysis to shape its responses. [Live demo](https://tinyurl.com/Ena-emotion)
- **[UniERP](https://github.com/BaconKage/UniERP)** - React and TypeScript ERP system backed by Firebase.
